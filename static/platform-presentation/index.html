QUALITY & TRUST

Only relevant, new evidence moves forward.

False matches and repeat stories are removed before they reach the user or the AI layer.

GATE 01✓

Relevance guard

Account-specific rules reject sport, showbiz, obituaries and known name collisions.

fetched → relevant / rejected
GATE 02#

Batch deduplication

Each article URL receives a stable SHA-256 hash; repeats inside the current fetch are dropped.

same hash in batch → discard
GATE 03DB

Historical deduplication

Stored hashes are checked before insertion, with a unique database constraint guarding races.

account_id + url_hash = unique
